# timemap-basishacks
A project for BasisHacks 2026 that reveals hidden history beneath the surface of modern cities.

TimeMap: Global Evolution
The Theme: Beneath the Surface

My project shows that history is hidden "Beneath the Surface" of our cities. Today we see modern buildings, but there is an old version of the city underneath. TimeMap lets you slide away the modern view to see the past.
How to Use the Program
Interactive Slider: Move the slider left or right to reveal the old city underneath the modern one.
Navigation Buttons: Use the left and right arrows to travel between seven different global cities.
Files:
HTML (index.html): Defines the structure of the website, including the buttons, the slider, and the viewing containers.
CSS (style.css): Handles the visual presentation and layering. It uses absolute positioning to stack the images exactly on top of each other.
JavaScript (script.js): Contains the logic for the application.
It uses an array to store the names and dates for seven different locations.
It uses functions to handle the navigation and the circular logic for the buttons.
It uses DOM manipulation to update the width of the top image in real-time when the slider is moved.

Included Locations:
Shanghai, China (1930 vs. 2026)
New York, USA (1920 vs. 2026)
Dubai, UAE (1990 vs. 2026)
Hong Kong, China (1960 vs. 2026)
London, UK (1920 vs. 2026)
Singapore (1970 vs. 2026)
Tokyo, Japan (1950 vs. 2026)
