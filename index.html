TimeMap: Shanghai

Exploring the temporal layers of the Pudong skyline. Beneath the surface of the world's most futuristic city lies a history of rapid transformation.

🕰️ THE PAST (1930s) TODAY (2026) 🏙️

SENIOR PATHWAY Project Documentation

Theme Interpretation: This project interprets "Beneath the Surface" through a temporal lens. It posits that the "surface" we experience today is merely the latest iteration of a site's history. By peeling back the modern pixel-layer, the user discovers the hidden physical history of Shanghai.

Technical Depth: The project utilizes Real-time DOM manipulation. A JavaScript event listener monitors the range input and dynamically recalculates the width of the top container. High-precision CSS positioning ensures that the background assets align perfectly across layers.
